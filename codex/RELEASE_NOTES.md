# DSH Codex Pet 0.4.0 · 首个预览版

将鲸鱼娘桌宠的喂食、玩耍、动作菜单、拖动和透明置顶窗口适配到 Codex 使用场景。聊天和手动碎碎念沿用现有 Codex 登录，额度查询显示真实套餐窗口的剩余百分比和重置时间。自动碎碎念默认关闭，可在设置中显式开启。

本次包含：

- macOS Apple Silicon 交互版、可恢复安装与卸载脚本。
- Codex 原生 v1 皮肤，九种动画状态。
- 源码增量、固定上游提交、构建说明和 SHA-256 校验文件。

交互版最低 macOS 12，仅提供 arm64 二进制；应用为临时签名，未经过 Apple 公证。聊天当前仅支持文字，需要已登录且支持相应 App Server 接口的 Codex；已验证 CLI `0.164.0-alpha.11.1`。原生皮肤没有 16 方向注视动作。

验证：59 项定向测试、源码及测试 TypeScript 检查通过；安装后的聊天、菜单、设置页、吃饭动画结束回执和配置重载均已验收。

安装：下载交互版外层 ZIP 并解压，保持内部 `DSH Codex Pet.app.zip` 原样，双击 `install.command`，再打开个人应用程序中的 DSH Codex Pet。喂食入口为「右键 → 动作 → 吃什么」。

源项目与动画：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。原型与设计署名见仓库授权说明。代码 MIT；角色和动画 CC BY-NC-SA 4.0，限非商业使用并保留署名。
