# DSH Codex Pet 0.4.4 · 修复裁切、动作卡顿与拖拽摆动

修复白龙娘动画中脚部被截断、头顶残留相邻帧脚部的问题。素材提取不再假定人物严格位于等分格内，而是根据实际不透明像素识别完整人物区域；源图保留充分留白，同组动作使用统一缩放和脚底锚点。

连续动作以 48 fps 共享 RGBA 光流补间生成姿态之间的过渡画面，颜色与透明度使用同一运动映射；细节可能轻微柔化。拖拽改用安静抱手姿态，保持朝向与抓取锚点，并消除位置取整反馈造成的摆动。

本次调整：

- 提取前检查人物是否触碰源图边界、是否完整，以及裁切区域是否混入相邻帧或未归属的可见部件；不满足要求时停止构建。
- 保留生成原图与逐帧区域记录，便于复查脚部、龙翼、尾巴和帧间留白。
- 已安装动画仅在 SHA-256 匹配已知旧内置版本时先备份再升级；未知内容按用户自定义保留。已有角色配置先备份，仅补入缺失的 `dragMotion`，其它设置和聊天记忆保留。

白龙娘继续提供待机、行走、转身、悬空轻扶，以及提裙礼、整袖、抿茶、阅卷、舒翼和颔首等动作。该形象参考用户提供的角色图，由内置 imagegen 生成透明素材，属于社区创作，非 OpenAI 官方角色；参考设计归原权利人，未对未知来源宣称获得授权或独占权利。

在「桌宠设置 → 宠物形象」选择角色后点击「使用此形象」，应用统一切换并重启。鲸鱼娘继续可选，角色外观设置和聊天记忆分别保留。对话标题与回复标签会使用当前角色名称。

常驻对话面板和实时模型选择继续可用。本次回归检查包括连续动作过渡、完整人物、边界留白、邻帧污染、稳定拖拽及备份升级。具体结果见发布包中的验证记录。

仅提供 macOS 12+、Apple Silicon（arm64）交互版。应用使用临时签名，未经过 Apple 公证；安装器保留系统隔离标记。聊天沿用已有 Codex 登录，仅支持文字；自动碎碎念默认关闭，开启后使用正常套餐额度。

安装：退出旧版，下载交互版外层 ZIP 并解压，保持内部 `DSH Codex Pet.app.zip` 原样，双击 `install.command`，再打开个人应用程序中的 DSH Codex Pet。
