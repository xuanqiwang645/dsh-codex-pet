# DSH Codex Pet 0.4.3 · 新增 ChatGPT 白龙娘

新增可选的白发紫眸 Q 版龙娘，参考本次用户提供的两张角色图，由内置 imagegen 生成透明素材。包含龙角、浅紫龙翼、卷尾和白紫服装，以及连续待机、行走、转身和悬空轻扶；日常小动作按高贵优雅的风格设计，包含提裙礼、整袖、抿茶、阅卷、舒翼和颔首，默认开启自主游走。社区创作，非 OpenAI 官方角色；参考设计归原权利人，未对未知来源宣称获得授权或独占权利。

在「桌宠设置 → 宠物形象」选择角色后点击「使用此形象」，应用统一切换并重启。鲸鱼娘继续可选，角色外观设置和聊天记忆分别保留。对话标题与回复标签会使用当前角色名称。

保留 0.4.2 的常驻对话面板和实时模型选择。257 项定向回归及两套 TypeScript 检查通过；角色素材已验证 640×360 画布、透明 Alpha 通道和身体点击范围。

仅提供 macOS 12+、Apple Silicon（arm64）交互版。应用使用临时签名，未经过 Apple 公证；安装器保留系统隔离标记。聊天沿用已有 Codex 登录，仅支持文字；自动碎碎念默认关闭，开启后使用正常套餐额度。

安装：退出旧版，下载交互版外层 ZIP 并解压，保持内部 `DSH Codex Pet.app.zip` 原样，双击 `install.command`，再打开个人应用程序中的 DSH Codex Pet。
