# DSH Codex Pet 0.4.1 · 移除网页宠物选项

修复 Codex 交互版选择「仅网页」后桌宠消失的问题。交互版本身没有网页宠物界面，本次删除「仅网页／两者」选项及「显示位置」子菜单，桌宠继续显示在透明桌面窗口中。

本次调整：

- 通过 macOS 菜单栏图标勾选宠物，隐藏或恢复桌面显示。
- 旧配置中的 `web`、`both` 自动按 `desktop` 读取；`none` 继续保持隐藏。
- 浏览器中的「桌宠设置」保留，用于调整聊天、大小和固定状态。

喂食、玩耍、动作菜单、拖动、聊天和额度查询继续可用。聊天和手动碎碎念沿用现有 Codex 登录，额度查询显示真实套餐窗口的剩余百分比和重置时间。自动碎碎念默认关闭，可在设置中显式开启。

本次包含：

- macOS Apple Silicon 交互版、可恢复安装与卸载脚本。
- Codex 原生 v1 皮肤，九种动画状态。
- 源码增量、固定上游提交、构建说明和 SHA-256 校验文件。

交互版最低 macOS 12，仅提供 arm64 二进制；应用为临时签名，未经过 Apple 公证。聊天当前仅支持文字，需要已登录且支持相应 App Server 接口的 Codex；已验证 CLI `0.164.0-alpha.11.1`。原生皮肤没有 16 方向注视动作。

验证：196 项定向回归、源码与测试 TypeScript 检查通过。已在本机更新后确认旧网页配置恢复桌面动画、菜单不再出现网页显示入口、失效显示模式请求被拒绝；原有配置、聊天记忆和原生皮肤均保留。

安装：下载交互版外层 ZIP 并解压，保持内部 `DSH Codex Pet.app.zip` 原样，双击 `install.command`，再打开个人应用程序中的 DSH Codex Pet。喂食入口为「右键 → 动作 → 吃什么」。
