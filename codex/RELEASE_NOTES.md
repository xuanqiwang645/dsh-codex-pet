# DSH Codex Pet 0.4.2 · 修复对话显示与模型选择

右键「对话」现在打开可持续查看的面板，包含聊天记录、发送按钮、等待状态和明确的错误提示。发送后面板保持打开，回答直接显示在记录中；再次打开可读取最近聊天记录。Enter 发送，Shift+Enter 换行，中文输入法选词不会误发。

「桌宠设置」的模型输入框改为下拉列表，读取本机 Codex 目录，支持刷新列表与跟随默认。选择并保存后，后续对话和碎碎念使用该模型；失效模型会明确提示，不自动替换已保存选择。面板中也可点击「选择模型」打开设置。

保留 0.4.1 的网页显示移除和旧配置恢复逻辑。更新保留宠物设置、聊天记忆和原生皮肤。

仅提供 macOS 12+、Apple Silicon（arm64）交互版。应用为临时签名，未经过 Apple 公证；安装器保留系统隔离标记。聊天沿用已有 Codex 登录、仅支持文字，需要支持相关 App Server 接口的 CLI；已在 `0.164.0-alpha.11.1` 验证。自动碎碎念默认关闭，开启后使用正常套餐额度。

验证：237 项定向回归和两套 TypeScript 检查通过；已通过本机界面选择其他模型、保存生效并完成真实对话。原模型偏好已恢复，测试消息已清理，原有配置和聊天记忆校验一致。

安装：下载交互版外层 ZIP 并解压，保持内部 `DSH Codex Pet.app.zip` 原样，退出旧版后双击 `install.command`，再打开个人应用程序中的 DSH Codex Pet。
