# DSH 鲸鱼娘 · Codex 交互版 0.4.2

**当前二进制仅支持 macOS 12 及以上的 Apple Silicon（arm64）Mac。** 应用使用本地临时签名，未经过 Apple 公证；macOS 可能需要用户手动确认才能打开。安装器保留系统隔离标记，不修改系统安全设置。

本版将 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的完整桌宠交互接到 Codex，保留原角色与透明动画。双击应用后，鲸鱼娘显示在独立的透明置顶窗口中，右键可打开交互菜单。

此前安装的「DSH 鲸鱼娘」原生皮肤继续可用。Codex 原生皮肤格式只承载动画；本交互版使用配套桌面程序承载喂食、玩耍、聊天和额度查询。如果两个宠物同时出现，可以在 Codex 中用 `/pet` 隐藏原生宠物，单独使用交互版。

## 安装与启动

1. 解压外层安装包，保持 **`DSH Codex Pet.app.zip` 原样**，与安装脚本放在同一目录；不要提前解压这个内部应用 ZIP。
2. 双击 `install.command`，或在终端运行 `bash "/完整路径/dsh-codex-companion/install.command"`。
3. 打开个人「应用程序」目录中的 **DSH Codex Pet**。
4. 右键宠物：喂食在「动作 → 吃什么」里，玩耍在「动作 → 玩耍」里；「对话」「碎碎念」「查看 Codex 额度」「桌宠设置」「退出桌宠」在菜单首层。

0.4.2 已移除「显示位置 → 仅网页／两者」等网页宠物入口，以及整个「显示位置」子菜单。通过 macOS 菜单栏图标勾选宠物，可隐藏或恢复桌宠。旧配置的 `web`、`both` 自动按 `desktop` 读取；原本的 `none` 保持隐藏。浏览器中的「桌宠设置」只用于调整配置。

默认安装位置为 `~/Applications/DSH Codex Pet.app`。安装器会直接在个人「应用程序」目录的临时文件夹内解压应用，并通过严格的签名与完整性校验后安装。内部应用保持 ZIP 形式，可避免同步目录重新附加 Finder 资源元数据而使签名失效。

安装器不会自动启动应用，不会设置开机启动，不会清除 macOS 的签名或隔离标记。同一应用的旧版会先备份，其他应用不会被覆盖。

## 聊天与额度

聊天与额度查询通过本机官方 `codex app-server` 连接，沿用你已登录的 Codex 账号，不需要另填 API 密钥。请先在 Codex 正常登录。安装器不修改 Codex 的登录文件、模型列表、默认模型或提供商配置。

需要提供相应 App Server 接口和命名权限配置的 Codex 版本；已在随桌面应用提供的 CLI `0.164.0-alpha.11.1` 上验证。版本不支持隔离配置时，聊天会明确停止，喂食和动画仍可使用。

「额度」显示 Codex 账号提供的用量窗口、剩余百分比和重置时间，并非人民币或美元余额。账号没有返回某项数据时，该项显示不可用；不会把缺失值当成零余额。聊天会消耗该 Codex 账号的正常用量。

自动碎碎念默认关闭，可在「桌宠设置」中显式开启，间隔至少 300 秒。手动碎碎念随时可用。当前聊天支持文字，并使用独立只读会话；对话记忆仅保存在本机。右键「对话」会打开保留聊天记录的面板，支持发送按钮、Enter 发送、Shift+Enter 换行；回答和错误会保留在面板中，关闭后可重新查看最近记录。点击面板中的「选择模型」或打开「桌宠设置」，可从本机 Codex 返回的目录选择模型；保存后用于下一次对话和碎碎念，也可选择跟随 Codex 默认。额度与聊天的连接方式参考 [OpenAI 官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## 数据、更新与恢复

交互版数据位于 `~/Library/Application Support/DSH Codex Pet/data/`，应用备份位于同一目录下的 `backups/`。此目录独立于原版 DSH 数据与 Codex 原生宠物目录。

更新前，先从宠物或托盘菜单退出交互版，再运行新版的 `install.command`。安装器会保留原数据，并将旧应用移入备份。

大小和固定状态可在设置中调整；隐藏与恢复使用菜单栏图标中的宠物勾选项。「重载配置」会重新启动交互版以应用设置。开机启动与自动弹出主应用均未设置。

双击 `uninstall.command` 可卸载：脚本将此应用移到备份目录，保留宠物数据。若要恢复，把备份中的 `DSH Codex Pet.app` 移回 `~/Applications/`；目标位置应没有同名应用。卸载交互版不会卸载原生 Codex 皮肤，也不会移除原版 DSH。
